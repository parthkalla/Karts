# Kart Combat Framework

Kart Combat Framework is a modular Unreal Engine plugin for building kart combat, racing, and battle-royale gameplay. It provides reusable vehicle movement, weapons, powerups, health and damage, inventory, match flow, race progression, respawn, play-zone, session, data-asset, and editor-validation systems.

## Highlights

- Network-ready kart movement, combat, weapons, projectiles, and deployables
- Race and battle-royale game modes with match-state flow and respawning
- Powerups, inventory, health/damage, play zones, checkpoints, and spawn points
- Data assets, data tables, gameplay tags, Blueprint libraries, and editor validators
- Optional Chaos Vehicles integration
- Documentation covering installation, multiplayer, dedicated servers, mobile input, and extension points

## Installation

Copy the `KartCombatFramework` folder into your Unreal Engine project's `Plugins` directory, enable the plugin in the editor, and rebuild the project when prompted. See [Documentation/Installation.md](Documentation/Installation.md) and [Documentation/QuickStart.md](Documentation/QuickStart.md) for setup details.
